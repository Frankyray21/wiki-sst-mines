## A1 — Frontmatter YAML : réparer les 170 infobox perdues + 3 champs manquants
**Impact critique · effort faible · `tools/build_site.mjs`**

Fusionne les constats « rendu #1 » et « contenu #1/#6/#7 ».

1. **l.141-144** — ne PAS assainir systématiquement (risque de régression sur 4407 frontmatters sains). Tenter `yaml.load` normalement, et n'assainir **que dans le catch** :
```js
p.fm = {};
if (m) {
  try { p.fm = yaml.load(m[1]) || {}; }
  catch {
    try { p.fm = yaml.load(sanitizeFm(m[1])) || {}; badFm.push(p.relPath + ' (réparé)'); }
    catch (e) { badFm.push(p.relPath + ' : ' + e.message); }
  }
  raw = raw.slice(m[0].length);
}
```
2. `sanitizeFm(block)` : pour chaque ligne `^(\s*[^:\s#][^:]*):[ \t]+(.+?)\s*$`, laisser intacte la valeur si elle commence par `'`, `"`, `|` ou `>` ; si elle est de la forme `^\[.*\]$`, la tester via `yaml.load('x: '+v)` et ne la guillemeter **que si ce test échoue** (c'est le cas `référence: [1978] 2 R.C.S. 1299` que la règle « contient : » rate) ; sinon la guillemeter si elle contient `:`. Guillemets simples, apostrophes internes doublées. Cas dominant mesuré : **146 lignes `visé:  : `** — si la valeur assainie se réduit à `:` ou à du vide, émettre `clé: ''` plutôt qu'une valeur ponctuation.
3. En fin de build : `if (badFm.length) console.warn(badFm.length + ' frontmatters illisibles :\n' + badFm.join('\n'))`. C'est la partie la plus utile : le silence du catch a coûté 170 fiches pendant toutes les générations précédentes.
4. **l.430-433 FM_LABELS**, tant qu'on y est (2 min, zéro risque) : ajouter `['revision','Révision']`, `['qualite','Qualité']` (31 notes amputées), `['en-vigueur-depuis','En vigueur depuis']` (2814 notes, donnée absente du corps), `['bloc','Bloc']` (1101), `['auteur','Auteur']` (38) ; supprimer l'entrée morte `['reference','Référence']`.
5. **l.495** : `const rev = p.fm['révision'] || p.fm['revision'] || p.mtime...`
6. **l.597** : injecter les alias dans le champ cherchable — `g: [...(Array.isArray(p.fm.tags)?p.fm.tags:[]), ...(Array.isArray(p.fm.aliases)?p.fm.aliases:[])].join(' ')`.

**Ne pas faire** : le fallback « re-parser ligne par ligne en clé:valeur » évoqué dans l'audit — il transformerait `tags: [recueil, loi]` en chaîne littérale et produirait des tags parasites `[recueil` / `loi]` via `String(tags).split()` l.452.

Puis `grep -rLc 'class="infobox"' docs/w/legislation --include=*.html | wc -l` et contrôle direct sur `http://localhost:8090/w/legislation/60-jurisprudence-marquante/r-c-sault-ste-marie-1978.html` (doit maintenant contenir une infobox) et `.../40-concepts-juridiques-transverses/adr.html` (lignes Qualité + Révision).
