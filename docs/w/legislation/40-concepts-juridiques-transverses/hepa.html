High Efficiency Particulate Air (filter). Filtre à particules à haute efficacité retenant au minimum 99,97 % des particules de 0,3 µm de diamètre aérodynamique (taille la plus pénétrante : MPPS).

Source : norme ISO 29463 (international), IEST-RP-CC001 (USA), EN 1822 (Europe), classification NIOSH 42 CFR 84 (N/R/P 100 pour APR).

Principe

Les filtres HEPA combinent quatre mécanismes de filtration

  1. Interception (grosses particules)
  2. Impaction inertielle (particules moyennes)
  3. Diffusion brownienne (particules ultra-fines < 0,1 µm)
  4. Attraction électrostatique (filtres électret)

Les particules de 0,3 µm sont les plus difficiles à capter : d'où le seuil de référence (MPPS : Most Penetrating Particle Size).

Applications en SST

  • Aspirateurs HEPA pour le nettoyage des poussières dangereuses (amiante, plomb, silice, DPM)
  • Cabines à pression négative dans les zones contaminées (zones amiante, salles d'isolement)
  • APR (appareils de protection respiratoire) à filtre P100 (équivalent HEPA : certification NIOSH)
  • Systèmes de ventilation locale pour confinement (laboratoires, cabines de pulvérisation, hottes)
  • Cabines pressurisées d'équipements miniers (camions, foreuses) : filtration de l'air entrant
  • Salles blanches, salles d'opération, laboratoires de niveau BSL-3/BSL-4

Classes (selon EN 1822 / ISO 29463)

Classe Efficacité (MPPS) Usage type
E10-E12 (EPA) 85-99,5 % Préfiltration
H13 (HEPA) 99,95 % Salles propres, médical
H14 (HEPA) 99,995 % Pharmaceutique, nucléaire léger
U15 (ULPA) 99,9995 % Microélectronique
U16 (ULPA) 99,99995 % Recherche, semi-conducteurs
U17 (ULPA) 99,999995 % Salles BSL-4

Équivalence APR (NIOSH 42 CFR 84)

Lettre Test Description
N NaCl (huile-NON résistant) N95, N99, N100
R DOP (huile-Résistant, durée limitée) R95, R99, R100
P DOP (huile-Permanent) P100 = équivalent HEPA

Pour l'amiante, le plomb, la silice et autres poussières dangereuses : utiliser P100 (filtre de couleur magenta).

En contexte minier québécois

  • APR P100 pour les tâches générant de la silice respirable (forage à sec, sablage, démantèlement)
  • APR P100 pour les fumées de soudage métalliques
  • Aspirateurs HEPA pour le nettoyage des aires de travail contaminées (résidus, surfaces poussiéreuses)
  • Cabines pressurisées HEPA sur les engins miniers modernes (camions, scoops) : réduction de l'exposition aux DPM et poussières
  • Filtration HEPA dans les systèmes de purificateurs d'air pour les refuges souterrains

Pièges courants

  • Confondre HEPA et N95 : N95 retient 95 % à 0,3 µm seulement : moins performant que HEPA/P100
  • Utiliser un filtre N95 pour de l'amiante (incorrect : exige P100)
  • Penser qu'un filtre HEPA filtre les gaz et vapeurs : il ne filtre que les particules (pour les gaz, il faut une cartouche chimique compatible)
  • Ne pas remplacer un filtre HEPA quand il devient encrassé (perte de débit, perte d'étanchéité possible)
  • Mal ajuster l'APR (fit-test obligatoire pour les APR ajustés) : l'efficacité du filtre n'est utile que si le masque est étanche
