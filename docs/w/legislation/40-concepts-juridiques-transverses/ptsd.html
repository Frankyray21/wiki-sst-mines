Post-Traumatic Stress Disorder. Terme anglais désignant le trouble de stress post-traumatique.

Voir la note principale : TSPT : contenu détaillé sur les critères diagnostiques DSM-5, la reconnaissance en LATMP, la démarche en cas d'événement traumatique et le contexte minier.

Usage du terme

  • PTSD : acronyme anglais utilisé internationalement, notamment dans le DSM-5 (American Psychiatric Association) et la littérature scientifique
  • TSPT : terme francophone, utilisé en clinique au Québec et dans les documents CNESST / INSPQ
  • ESPT : variante française parfois rencontrée (état de stress post-traumatique)
  • Dans la CIM-11 (OMS, 2022) : code 6B40 pour PTSD ; code 6B41 pour Complex PTSD

Distinction PTSD vs autres troubles connexes

  • PTSD complexe (CIM-11) : trauma répété (abus chronique, captivité, travail à risque continu)
  • Trouble de l'adaptation : réaction à un stress non traumatique (perte d'emploi, conflit)
  • Trouble de stress aigu : symptômes < 1 mois après l'événement
  • Trouble dissociatif : peut accompagner un PTSD sévère
