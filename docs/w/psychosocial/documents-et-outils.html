Comment alimenter ce dossier

  1. Télécharger les documents officiels depuis les sources citées
  2. Renommer en suivant la convention : [Nom court], [Source], [Année].pdf
  3. Déposer dans le sous-dossier approprié
  4. Ajouter le lien interne dans l'article concerné via wikilink ou lien !fichier.pdf pour intégration
💡Astuce

Pour les documents qui se mettent à jour souvent (gabarits CNESST, grilles INSPQ), conserver la date de téléchargement dans le nom du fichier et vérifier annuellement.
